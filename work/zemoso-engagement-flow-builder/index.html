Case Study · Zemoso Technologies

Engagement Flow Builder

Role  UX DesignerCompany  Zemoso TechnologiesTimeline  2022–2023
+29%feature adoption

The problem

I directed design on a $6.2M healthcare platform, working across web and mobile with no shared design system to keep them consistent. New features were being designed and built one at a time, so patterns drifted between screens and engineering kept re-solving the same interaction problems.

What I worked on

Alongside the day-to-day feature work, I built an atomic design system to standardize components across the product, and designed the Engagement Flow Builder, a tool that let the team configure how and when the platform nudges patients through multi-step care flows.

  • Defined the atomic components (buttons, form patterns, states) used across web and mobile, so new features shipped consistent by default
  • Interviewed the internal team building patient-facing flows to understand where they were duplicating work
  • Designed the flow builder's configuration screens so non-designers could adjust an engagement sequence without opening a ticket
  • Partnered closely with engineering throughout, which is a large part of why implementation delays dropped by roughly 35% over the year

The result

We shipped 25+ features in the first year on the new system.
